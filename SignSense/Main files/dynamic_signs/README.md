# Dynamic sign reference videos

Put one reference MP4 for each dynamic Auslan sign in this folder.

Name files after the sign, for example `hello.mp4`, `thank-you.mp4`, or
`how-are-you.mp4`. The filename becomes the exercise label. When Exercise 1
opens, SignSense extracts MediaPipe landmarks from every video and uses that
movement trajectory as its DTW reference.

Use one sign per video. Record front-on with the signer visible from their head
to both hands, and leave a short still moment before and after the sign.
